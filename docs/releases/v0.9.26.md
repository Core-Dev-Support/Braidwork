Релизная сборка (Release APK) с постоянной цифровой подписью.

## Исправление разметки: нижнее меню и главный экран

В v0.9.25 нижнее меню (`BottomBar`) получило `heightIn(min = 84.dp)` вместо фиксированной высоты `height(84.dp)`, но внутри сохранялся модификатор `fillMaxSize()`. В результате контейнер меню забирал всю доступную высоту экрана, центрировал вкладки ровно посередине дисплея и вытеснял основной экран («Моя сеть») в нулевую высоту.

* Вложенный `Row` переведён на `fillMaxWidth().align(Alignment.Center)`. Меню занимает строго 84 dp (или увеличивается по содержимому при крупном системном шрифте), а экраны получают всю остальную высоту через `Modifier.weight(1f)`.
* Подписи вкладок получили `maxLines = 2`, чтобы переноситься при системном масштабе шрифта 1.3 без усечения.

## Постоянная цифровая подпись (Release)

Приложение переведено на постоянный релизный ключ подписи:
* Схемы подписи: **v1, v2, v3** (полная совместимость с современными версиями Android).
* Реквизиты сертификата: `CN=Core Dev Support, OU=Development, O=CDS Core Dev Support, L=USA, ST=US, C=Washington`.
* После установки этой версии последующие релизы можно будет обновлять накатом поверх существующего приложения без удаления данных.
