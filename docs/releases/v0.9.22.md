## Высоты, заданные числом, — конец аудита

В v0.9.21 высоты в общих компонентах стали минимумами. Теперь то же доведено
до восьми экранов, где высота была зашита числом рядом с текстом:

| Экран | Было | Стало |
|---|---|---|
| Настройки, строка | 64 dp | минимум 64 dp |
| Внешний вид, вариант | 56 dp | минимум 56 dp |
| Внешний вид, строка с подписью | 56 или 66 dp | минимум 56 или 66 dp |
| Сопряжение, шаг | 66 dp | минимум 66 dp |
| Фон, шаг | 66 dp | минимум 66 dp |
| Фон, название | 44 dp | минимум 44 dp |
| Семья, участник | 72 dp | минимум 72 dp |
| Семья, кнопка приглашения | 52 dp | минимум 52 dp |
| Обмен, строка файла | 52 dp | минимум 52 dp |
| Уведомления, кнопка трансляции | 56 dp | минимум 56 dp |
| Приветствие, обе кнопки | 56 dp | минимум 56 dp |

Почему это важно. Compose масштабирует `sp` сам, но **не ломает заданную
высоту**: строка в две строки при системном шрифте 1.3 не влезает в 48 dp, и
Compose её срезает. При этом масштаб шрифта у человека не поломка настроек, а
обычная потребность — читать крупнее.

Обрезанная надпись хуже переноса: человек видит половину слова и не знает,
нажимать ли.

Кнопкам добавлено вертикальное поле. Без него строка, выросшая выше минимума,
упирается в края скругления, и радиус срезает углы текста.

## Что специально осталось фиксированным

Не всё переведено на минимумы, и это осознанно:

- разделители 1–2 dp, отступы `Spacer`, полосы прогресса 8 dp, полосы ввода кода
  8 dp — это не контейнеры с текстом, они не должны расти;
- иллюстрация на экране приветствия 300 dp — это рисунок на холсте, у него нет
  содержимого, которое можно обрезать.

Правило простое: **минимум — везде, где внутри есть текст; точная высота —
везде, где текста нет.**

## Чего в этой версии нет

**Тип устройства.** Карточка по-прежнему показывает «Ноут» для любого
устройства. Настоящий тип знает только отправляющая сторона — у неё есть экран,
ввод и окно, — значит он должен объявляться в объявлении рядом с платформой.
Правка нужна сразу в шести местах: схема протокола, транспорт, сборка `Hello`,
разбор объявления, событие, клиент. Бросать такую цепочку на середине хуже, чем
не начинать: сломанное объявление уронило бы обнаружение целиком.

Пока значения нет, показывать надо честное «неизвестно», а не ноут по
умолчанию — иначе это же враньё просто переедет на другую строку.
