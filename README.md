# Braidwork

Связь между устройствами без сервера и без аккаунта. Работает между любыми Android-устройствами, Windows и Linux.

Название — от плетения: из отдельных нитей получается полотно, ровно как из отдельных устройств семья.

## Что это

Одна семья устройств вместо связки «телефон с компьютером». Между ними работает общий буфер обмена, передача файлов, галерея, уведомления, зеркало экрана, звонки и управление плеером.

Ключевые отличия от существующих решений:

- **Нет сервера и нет аккаунта.** Четыре из пяти транспортных каналов работают вообще без интернета. Для связи через интернет используется STUN, он бесплатный и не требует регистрации.
- **Любые устройства.** Связка не ограничена парой производителей: Vivo с Linux работает так же, как с Windows.
- **Семья, а не пара.** Новое устройство вводит уже доверенный участник, а не проходит отдельное сопряжение с каждым.
- **Дальность.** Устройства связываются между разными сетками через интернет.
- **Низкий расход батареи.** Измеряется и показывается в интерфейсе, а не обещается.

Apple служит ориентиром по ощущению и качеству, но его приём недоступен: Continuity держится на своём железе и своём закрытом протоколе. Здесь то же самое сделано на чужом железе и по открытому протоколу.

## Состояние

Проект на начальной стадии. Есть спецификация протокола, схема сообщений, ядро с идентичностью устройства и криптографией. Клиентов ещё нет.

## Устройства

| Платформа | Язык клиента | Мост к ядру |
|---|---|---|
| Ядро | Rust | — |
| Android 6+ | Kotlin + Compose | JNI |
| Android 5 | Kotlin, `minSdk 21` | JNI |
| Windows 10/11 | Kotlin или C# | C ABI |
| Linux | Kotlin/JVM или Rust + GTK4 | C ABI |
| HarmonyOS NEXT | ArkTS + ArkUI | NAPI |

iPhone полноценным участником не станет: iOS не отдаёт наружу буфер обмена, уведомления сторонним приложениям и захват экрана. Обмен файлами с iOS можно сделать отдельно.

## Сборка ядра

Нужны Rust с целями под нужную платформу и линкер MSVC.

```sh
rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android i686-linux-android

cargo build --manifest-path core/Cargo.toml
cargo test  --manifest-path core/Cargo.toml
```

Для Android дополнительно нужна переменная `ANDROID_NDK_HOME`.

## Приватность

Открытый код, шифрование Noise XX из коробки, локальный режим без сети, никакой телеметрии. Ключи устройства создаются локально и никуда не отправляются. Идентификатор вычисляется из публичного ключа подписи, а не выдаётся сервером.

Единственное исключение — сообщение содержит имя устройства, которое отправитель передал, и это видно всем участникам семьи.
